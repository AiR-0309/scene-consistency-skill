# Scene Consistency · 场景一致性

将概念图、多房间场景图、多机位参考或布局草图整合为可连续拍摄的空间设定，用于 AI 影像的空镜、反打及角色入景。

## 安装

在 Codex 中发送：

> 使用 $skill-installer 安装 https://github.com/AiR-0309/scene-consistency-skill ，技能名称设为 scene-consistency。

也可以手动克隆到个人技能目录的 scene-consistency 文件夹。

## 使用

附上参考图片后发送：

> 使用 $scene-consistency，根据这些图片和布局草图生成完整场景平面图。

确认布局后继续：

> 相机放在客厅东南角，高度 1.5 米，朝西北平视，生成一张无人场景图。

支持一次提供同一场景的多个房间和不同视角。请说明材料属于同一场景还是仅作风格参考，并指出优先采用的版本。

## 工作流程

1. 清点材料、匹配房间与机位，记录证据和冲突。
2. 判断整体功能，补全必要的画外分区与通路。
3. 建立配色、材质、生活痕迹与陈设档案。
4. 生成标注东西南北的完整俯视布局，等待用户确认。
5. 根据具体机位生成空镜，核验空间和陈设后加入角色。

平面图约束建筑、大件家具和空间关系。原始场景图指导小件陈设、配色、材质和生活气质。小物经核验采用后按故事时刻保持连续。

## 文件

- SKILL.md 是技能入口与执行规则。
- references/production-design.md 包含配色、材质、生活痕迹的记录方法及影视制作来源。

## 能力边界

单张图的隐藏空间和尺寸存在歧义，补全部分会标为推定。图像生成仍可能产生透视、物件或材质偏差，需要逐镜头检查与修复。此工作流支持概念设计与影像连续性，精确空间还原需要实测、多视角或三维模型。

需要具有图片查看与生成能力的执行环境。技能本身不包含图像生成模型或 API 密钥。
